# Recursos creados por paso y cómo se borran

`C` = `CLUSTER_NAME`, `A` = cuenta. "Ámbito": **clúster** = se borra en el teardown normal; **cuenta** = compartido, solo con `--purge-account-shared`; **protegido** = nunca.
La columna "Fase" es la del `teardown.sh` (la fase `A` es la de apps-layer, la primera; no confundir con `A` = cuenta).

| Paso | Recurso | Ámbito | Cómo se identifica | Cómo se borra | Fase |
|---|---|---|---|---|---|
| 1 | Usuario IAM `cloud-provisioner` + `AdministratorAccess` + access key(s) | **cuenta** | nombre exacto | borrar keys -> desadjuntar -> `delete-user`; el ÚLTIMO; no puede ser el llamador | 9 |
